# Multimodal Breast Cancer Relapse-Free Survival Prediction using Explainable AI

This repository contains the complete implementation of a multimodal Transformer framework for predicting breast cancer relapse-free survival (RFS) by integrating clinical, genomic, and histopathology features. The project also includes explainability analyses using SHAP and Transformer attention, as well as comparisons against traditional survival models including Cox Proportional Hazards and Random Survival Forest.
